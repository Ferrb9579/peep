PEEP — QUALITY OF LIFE AND INTERACTION POLISH
Completed: 2026-10-28 (Asia/Kolkata)

CHANGES
- Session-only drafts per direct/group conversation, including cursor position;
  preserved through navigation/reconnect and cleared after sending or sign-out.
- Desktop Enter sends; Shift+Enter inserts a line at the selection. Sending
  retains focus, empty/disabled composers cannot send, and IME composition is
  protected. Attachment preparation rejects duplicate requests and shows state.
- Remote arrivals follow the latest view only when already near the bottom.
  Reading older messages preserves position and shows a new-message count.
- Conversation search matches text, attachment names and sender names; Ctrl/Cmd+F
  opens it, Escape closes it, and closing restores the earlier reading position.
- Message menus copy text with feedback or insert a plain-text quote while
  preserving the existing composer draft. No new delivery/read status is implied.
- Ctrl/Cmd+K focuses inbox search; Escape clears it. Empty filtered views offer
  Reset filters, and refresh actions show progress and prevent repeated requests.
- Call shortcuts M/V/F/G control microphone/camera/video focus/layout. Desktop
  help lists the keys. A visible muted reminder remains in expanded video.
  Keyboard shortcuts do not activate through a modal dialog.
- Media settings show unsaved edits, highlight the matching preset, restore
  defaults, and confirm saving. Screen-only restore leaves audio/camera intact.
- Press, icon and tab transitions, ringing entrance and chat auto-scroll respect
  reduced motion. Feedback replaces stale queued snackbars.
- System Back from a conversation returns to inbox and preserves its draft.

LIMITS
Desktop browser emulation is not physical Android/iOS testing. Physical capture,
OS screen pickers, touch gestures, cross-browser behavior and lossy production
networks remain outside this pass. The synthetic harness is JavaScript-only;
production compilation passes the WebAssembly dry run. The existing Cupertino
font-family warning remains; the app does not use CupertinoIcons.
